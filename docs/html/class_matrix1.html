Detailed Description

template<typename T>
class Matrix1< T >

Clase template que representa una matriz 2D dinámica.

Implementa operaciones algebraicas básicas (suma, resta, multiplicación), eliminación gaussiana (REF y RREF) con paralelismo via std::thread, cálculo de determinante, transposición, y acceso por índice.

Template Parameters
TTipo numérico de los elementos (int, float, double).
Ejemplo de uso:
Matrix1<double> m(3, 3);
m[0][0] = 1.0; m[1][1] = 5.0; m[2][2] = 9.0;
Matrix1<double> t = m.Transpose();
double det = m.Determinant();

Calcula el determinante via eliminación gaussiana paralela.

Determinante de la matriz.

Reutiliza GaussElim y acumula el producto de los pivotes, ajustado por el signo de los intercambios de filas.

Precondition
La matriz debe ser cuadrada (m_rows == m_cols).
Returns
Determinante de tipo T.
Note
Para matrices enteras puede haber truncamiento. Usar Matrix1<double>.

Núcleo compartido de eliminación gaussiana con threads.

Eliminación de Gauss.

Realiza eliminación hacia adelante (REF) o completa (RREF). Cada fila de eliminación se procesa en un std::thread independiente.

Parameters

reducedtrue para RREF, false para REF (default).
Returns
Vector de pivotes encontrados en cada columna.
